# Publishing Guide

This tap is deprecated. The active Homebrew tap for `badger` is now `PVRLabs/homebrew-tap`.

## Current Publish Target

Update the shared tap instead:

```text
https://github.com/PVRLabs/homebrew-tap
Formula/badger.rb
```

Use this install path in public docs:

```bash
brew install pvrlabs/tap/badger
```

## Deprecated Tap

Do not publish new formula updates here unless a temporary compatibility update is explicitly needed. Keep this repository as a redirect/deprecation surface for existing users of `pvrlabs/aibadger`.
